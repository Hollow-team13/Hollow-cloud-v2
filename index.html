Trust center

Segurança por padrão.

O frontend nunca deve conhecer tokens, senhas, tokens de bot ou a lista completa de supervisores.

Checklist de produção
Itens que o backend precisa garantir
Credenciais server-side · tokens Discord e SMTP ficam em secrets do servidor, nunca no HTML ou GitHub Pages.
Obrigatório
Allowlist de supervisor · autorização por ID no backend, com sessões curtas e MFA recomendado.
Obrigatório
Runtime resiliente · worker com health check, backoff e alertas; “online para sempre” não pode ser garantido por um site estático.
Obrigatório
Upload isolado · ZIP deve ser verificado, extraído em sandbox, limitado por tamanho e bloqueado contra path traversal.
Obrigatório
O que este site não faz sozinho

GitHub Pages não executa processos, não envia e-mail de verificação e não protege credenciais. Ele é a camada visual pública.
